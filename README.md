One word for the human you work for. The funniest, most fitting word wins.

## Entry

**Hoverer** — the boss who stands behind your chair, watching you type.

## Run

```sh
python3 main.py
```

Writes the word to `/output/entry.txt`, validated as exactly one alphabetic
word of 1–30 characters, with a read-back check that the file holds it.
